# Module allowlist for the RG34XX-SP kernel.
#
# kernel/build-kernel.sh turns OFF every option that the base config (defconfig + platforms off +
# rg34xxsp.config) builds as a module (=m), unless it is:
#   - set in kernel/config/rg34xxsp.config, or
#   - the driver of an enabled node in one of the RG34XX-SP device trees
#     (found by tools/dt_driver_coverage.py --symbols), or
#   - matched by a pattern below (shell-style globs on the symbol name, without CONFIG_).
# Options another kept option selects come back on their own; build-kernel.sh reports them.
# Built-in (=y) options are not touched here.
#
# One pattern per line; text after '#' is the reason.

## Wi-Fi and Bluetooth stacks (the board's RTL8821CS needs them)
CFG80211                # rtw88 depends on it
MAC80211                # rtw88 depends on it
RFKILL                  # Wi-Fi/BT on-off switch used by NetworkManager, iwd and bluetoothd
BT                      # Bluetooth core
BT_HIDP                 # classic Bluetooth keyboards and pads

## Display, GPU and video engine: Allwinner and Mali parts only

DRM_EXEC
DRM_GPUVM

DRM_DISPLAY_HELPER
DRM_CLIENT_LIB
DRM_CLIENT_SELECTION
DRM_SUN*                # Allwinner display engine, TCON and HDMI glue (for when H616 display lands)
!DRM_SUN6I_DSI          # MIPI DSI: the RG34XX-SP panel is RGB with a 3-wire SPI setup, not DSI
DRM_DW_HDMI*            # the HDMI controller the sun8i HDMI glue wraps (mini-HDMI port)
DRM_PANFROST            # Mali-G31
BACKLIGHT_CLASS_DEVICE  # panel backlight, once the display series lands
BACKLIGHT_PWM
MEDIA_SUPPORT           # Cedrus video engine depends on these
VIDEO_DEV
VIDEOBUF2_*
V4L2_MEM2MEM_DEV
V4L2_H264
V4L2_VP9
V4L2_JPEG_HELPER

SND_AUDIO_GRAPH_CARD*

## Input and IIO helpers the stick driver uses
