# ReduxOS brand assets

Logos, device renders, promo graphics and UI concept renders for
ReduxOS — Allwinner H700. All desk/concept art; nothing here is a photo of a
validated device.

## Palette — "Redux Quad"

| Role        | Hex       | RGB            |
|-------------|-----------|----------------|
| Black       | `#0B0C0E` | 11, 12, 14     |
| Orange      | `#FE732D` | 254, 115, 45   |
| Orange (dk) | `#BD4514` | 189, 69, 20    |
| Green       | `#40CC70` | 64, 204, 112   |
| White       | `#ECEEF0` | 236, 238, 240  |

Orange = accents, selection and arrows; green = OK / enabled status; white =
body text; black = ground.
