# Claude / AI session rules — ReduxOS — Allwinner H700

See [`AGENTS.md`](AGENTS.md) for the collaboration rules and [`CONTRIBUTING.md`](CONTRIBUTING.md) for the
contribution rules. README ground rules win where they differ.
