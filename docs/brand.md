# Brand

**ReduxOS** — *Handheld Freedom. Hardware Unlocked.*
Strapline under the mark: **Linux · Ubuntu 24.04 LTS Noble**.

The mark is a crowned gear with an **R** (the "ReduxOS crown"). The project's own original artwork; it is
not derived from Anbernic, Allwinner, or Canonical/Ubuntu branding, and ReduxOS is not affiliated with them.

## Logo variants (in `assets/brand/`)
| File | Finish | Use |
|---|---|---|
| `ReduxOS-logo-bronze.png` | Bronze | **Current — the build phase** (pre-beta). This is the active logo now. |
| `ReduxOS-logo-silver.png` | Silver | **Beta** — switch the headline logo to this at the beta milestone. |
| `ReduxOS-logo-gold.png` | Gold | **Release** — switch to this at the 1.0 release milestone. |
| `ReduxOS-logo-monogram.png` | Orange C+R monogram | **Promotion** — social/marketing and general promotional use. |

### Medal-tier progression (Dale, 2026-11-20)
Bronze → Silver → Gold, tied to project stage: **bronze while building, silver at beta, gold at release.**
The orange monogram is the general promotional mark. To advance a phase, swap the logo referenced at the top
of `README.md` to the next finish and set the repo's social-preview image to match.

## Usage notes
- README header currently points at the bronze logo.
- Set the GitHub **social preview** image (Settings → General → Social preview) to the current-phase logo.
- Keep the tagline wording exact: "Handheld Freedom. Hardware Unlocked."
